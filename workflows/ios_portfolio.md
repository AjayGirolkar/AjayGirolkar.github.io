# 🚀 Workflow: Build High-Conversion iOS Freelancing Portfolio

## 🎯 OBJECTIVE
Create a premium, high-conversion portfolio website for a Senior iOS Developer that:
- Attracts high-paying freelance clients
- Builds personal brand authority
- Converts visitors into leads (contact / booking)

---

## ⚠️ EXECUTION RULES (STRICT)

- Follow token_optimization.md strictly
- Work ONLY in defined phases
- DO NOT skip phases
- DO NOT generate full website at once
- DO NOT repeat previous outputs
- Ask for confirmation before moving to next phase
- Keep responses concise and focused

---

## 🧠 TARGET PROFILE

- Role: Senior iOS Developer / Architect
- Experience: 10+ years
- Strength: Scalable apps, architecture, performance
- Target Clients:
  - Startups (MVP, scaling)
  - Product companies
  - Founders

---

# 🟢 PHASE 1: POSITIONING (NO CODE)

## Goal:
Define a strong positioning strategy to differentiate from generic developers.

## Agent Tasks:
1. Propose 3 positioning directions:
   - Premium Consultant (high-ticket clients)
   - Startup Specialist (MVP to scale)
   - Personal Brand Authority (content-driven)

2. For each:
   - Target audience
   - Value proposition
   - Pricing perception
   - Pros/cons

## Output:
- Concise comparison
- Ask user to select ONE direction

## Constraints:
- No code
- No UI
- Keep under 150–200 words

---

# 🟢 PHASE 2: WEBSITE STRUCTURE (BLUEPRINT)

## Goal:
Define clear sitemap and sections.

## Agent Tasks:
- Create section list only

## Expected Sections:
- Hero
- Social Proof
- About
- Services
- Case Studies
- Tech Stack
- Process
- Testimonials
- Pricing (optional)
- Contact

## Output:
- Ordered list of sections
- Short purpose for each

## Constraints:
- No content writing yet
- No design
- No code

# 🟢 PHASE 3: DESIGN SYSTEM

## Goal:
Define consistent visual identity.

## Agent Tasks:

  - Typography

  - Component style (cards, buttons)

## Output:
- Structured design tokens

## Constraints:
- No implementation
- Keep concise

# 🟢 PHASE 4: CONTENT CREATION (CHUNKED)

## Goal:
Create high-conversion copy.

## Agent Tasks:
Generate ONE section at a time:

### Order:
1. Hero
2. About
3. Services
4. Case Studies
5. CTA

## For each section:
- Clear headline
- Supporting text
- CTA (if needed)

## Constraints:
- Do NOT generate all sections together
- Wait for approval before next section
- Focus on outcomes, not tech jargon

---

# 🟢 PHASE 5: CASE STUDIES (HIGH IMPACT)

## Goal:
Show real value, not just projects.

## Agent Tasks:
For each project:
- Problem
- Solution
- Tech used
- Results (impact)

## Output:
- Story format

## Constraints:
- Avoid generic descriptions
- Focus on business impact
